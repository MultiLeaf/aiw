# Vite Frontend

Inspect the Vite entry point, framework plugins, route/component structure, and workspace-local scripts before making changes. Follow the existing component, state, styling, accessibility, and API-client patterns. Keep frontend configuration scoped to the correct workspace. Add focused tests with the configured runner and verify the workspace's declared lint, typecheck, and build commands. Do not assume that a root-level command applies to every app in a monorepo.
