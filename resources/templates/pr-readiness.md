# PR Readiness

## PR Reference

PR number or URL, e.g. #42.

## Branch

Feature branch → base branch.

## CI Evidence

Command, result, and link (e.g. `gh pr checks`: all pass).

## Review Comments

Total comments, resolution evidence, and a line ending in `unresolved: 0`.

## Conflict Check

Merge state: clean / no conflicts (or conflicts with a resolution plan).

## Merge-Ready Checklist

- [ ] CI green on the PR
- [ ] All review comments resolved (unresolved: 0)
- [ ] No merge conflicts with the base branch
- [ ] Human-only: branch protection and required approvals satisfied
